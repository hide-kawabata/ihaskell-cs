# IHaskell environment of Jupyter Notebook in GitHub Codespaces
(GitHub Codespaces の Jupyter Notebook で IHaskell を使う)

1. Copy (clone or fork) this repository. (このリポジトリを自分の Github リポジトリとしてコピーする)
2. Click the (green) `Code` button and select the `Codespace` tab. (`Code` をクリック -> `Codespace` タブを選択)
3. Create (or launch) a codespace. (Codespaceを新規作成 or 起動)
