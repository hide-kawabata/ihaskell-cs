# IHaskell environment for Jupyter Notebook in GitHub Codespace (GitHub Codespace の Jupyter Notebook で IHaskell を使う)

## On the first day
1. Click the (green) `Code` button and select the `Codespace` tab. (`Code` をクリック -> `Codespace` タブを選択)
2. Open Codespace. (Codespaceを起動)
3. Enjoy learning Haskell.
4. "Commit" changes and "Sync Changes / Push". (変更分をコミット＆プッシュ)
    Your codespace will be automatically forked into your GitHub repositories. (自動的にフォークされる)
5. Command Palatte -> Codespaces: Stop Current Codespace. (Codespaceを停止)

## On the second day and later
1. Check [your codespaces](https://github.com/codespaces) and select the codespace you used before.
2. Enjoy learning Haskell.
3. "Commit" changes and "Sync Changes / Push". (変更分をコミット＆プッシュ)
4. Command Palatte -> Codespaces: Stop Current Codespace. (Codespaceを停止)
